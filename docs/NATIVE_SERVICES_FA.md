# سرویس‌های بومی و امنیت حساب

تمام آدرس‌ها نمونه‌اند. این سرویس‌ها برای Linux هستند؛ کانتینر وب به‌تنهایی آن‌ها را اجرا نمی‌کند.

## AmneziaWG

در نصب جدید گزینهٔ `--amneziawg` را اضافه کنید. در نصب موجود:

```bash
sudo bash /opt/spectergate/deploy/amneziawg_install.sh
sudo systemctl status spectergate-amneziawg awg-quick@sg-awg0
```

نصب به Go نسخهٔ ۱٫۲۱ یا بالاتر برای راه‌اندازی ابزار ساخت، دسترسی به منابع رسمی Go/GitHub و رابط TUN نیاز دارد. سورس موتور و ابزارها با commit مشخص ساخته می‌شوند.

پورت پیش‌فرض `51821/UDP` و شبکهٔ داخلی ثابت `10.89.0.0/24` است؛ پورت را در فایروال ارائه‌دهنده هم باز کنید. WireGuard معمولی شبکه و کلیدهای دیگری دارد. برای پورت دیگر:

```bash
sudo bash /opt/spectergate/deploy/amneziawg_install.sh --port 51830
```

پورت پارامترهای پنل را هم با همان مقدار هماهنگ کنید. سرویس root اجازهٔ تغییر نام رابط یا شبکهٔ ثابت از پنل را نمی‌دهد.

در **AmneziaWG**، مدیر دارای مجوز مدیریت تنظیمات، کاربر را جست‌وجو و انتخاب می‌کند و دسترسی می‌دهد. پس از چند ثانیه فایل کانفیگ یا لینک و QR قابل دریافت است. مدیر خواننده فقط کانفیگ کاربری را می‌گیرد که در محدودهٔ اوست و قبلاً مجوز گرفته است. تغییر پارامترهای مبهم‌سازی نیازمند کانفیگ جدید کاربران است.

کلید خصوصی سرور root-owned است. حجم، انقضا و غیرفعال‌سازی کاربر در manifest اعمال می‌شوند؛ رابط root فقط peerهای مجاز را نگه می‌دارد. با توقف companion، پاک‌سازی peerها در systemd اجرا می‌شود.

```bash
sudo journalctl -u spectergate-amneziawg -n 80 --no-pager
sudo /usr/local/bin/awg show sg-awg0
```

پیش از تحویل، اتصال را از شبکه و برنامهٔ واقعی مقصد تست کنید.

## SSL

در نصب جدید سرویس خودکار نصب می‌شود. برای نصب موجود:

```bash
sudo bash /opt/spectergate/deploy/ssl_install.sh
sudo systemctl status spectergate-ssl certbot.timer
```

رکورد DNS باید به سرور برسد و TCP 80 برای challenge در دسترس Nginx باشد. در **گواهی‌های SSL** دامنه و ایمیل اختیاری را وارد کنید. عملیات ممکن است چند دقیقه طول بکشد. در شکست، خطا نمایش داده می‌شود و گواهی خودامضا جای آن قرار نمی‌گیرد.

صدور و تمدید با Certbot و افزونهٔ Nginx است. گواهی‌های کاتالوگ با دسترسی محدود برای هسته در این مسیر آماده می‌شوند:

```text
/var/lib/spectergate-certificates/vpn.example.com/fullchain.pem
/var/lib/spectergate-certificates/vpn.example.com/privkey.pem
```

مسیرها را در اینباند TLS انتخاب کنید. وب دسترسی اجرای فرمان دلخواه root ندارد. با تمدید، Nginx reload می‌شود و هسته تغییر فایل را تشخیص می‌دهد. ری‌استارت هسته اتصال‌های موجود را قطع می‌کند. صدور گواهی، دامنه و virtual host پنل را تغییر نمی‌دهد. گواهی دستی تمدید خودکار ندارد.

```bash
sudo journalctl -u spectergate-ssl -n 80 --no-pager
sudo certbot renew --dry-run
```

## IPهای آنلاین و تست مسیر

**IPهای آنلاین** اطلاعات API هستهٔ محلی را حدود هر پنج ثانیه می‌گیرد. این سقف، دستگاه فیزیکی را شناسایی نمی‌کند؛ NAT و تغییر IP نتیجه را تغییر می‌دهند. محدودیت فعلاً روی نود راه دور و WireGuard/AWG نیست.

قطع اتصال یا اعمال IP اضافه، قانون همان کاربر/IP را ده دقیقه ثبت و هسته را ری‌استارت می‌کند؛ دیگر کاربران باید دوباره وصل شوند. قطع دستی مجوزهای `users.write` و `xray.manage` و دسترسی به همان کاربر می‌خواهد.

تست مسیر از قواعد **اعمال‌شده** استفاده می‌کند؛ ذخیرهٔ فرم به‌تنهایی اعمال نیست. هسته باید در حال اجرا باشد. تست، انتخاب خروجی را نشان می‌دهد و موفقیت اتصال اینترنت یا تونل را تضمین نمی‌کند. تست TCP مستقیم هم از مسیر سیستم‌عامل است و آزمون WARP نیست.

## ورود دومرحله‌ای

از **حساب من**، 2FA را راه‌اندازی کنید، QR را با Authenticator بخوانید و کدهای بازیابی را امن نگه دارید. setup ده دقیقه اعتبار دارد. با فعال یا غیرفعال‌شدن 2FA باید دوباره وارد شوید.

کلید TOTP رمزگذاری و کدهای بازیابی هش می‌شوند؛ هر کد بازیابی فقط یک‌بار مصرف است و TOTP پذیرفته‌شده دوباره پذیرفته نمی‌شود. اطلاعات نسخهٔ قبلی هنگام شروع برنامه منتقل می‌شوند. فایل `backend/data/secrets.key` را همراه بکاپ کامل نصب امن نگه دارید؛ بدون آن کلیدهای رمزگذاری‌شده بازیابی نمی‌شوند.
