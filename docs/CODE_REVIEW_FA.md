# نتیجهٔ اصلاح ایرادهای بررسی کد

## اصلاحات

- **AmneziaWG:** جدول peer، کلیدهای رمزگذاری‌شده، شبکهٔ IPv4، شمارنده‌های مصرف، مجوزهای کاربران و سرویس root مستقل دارد. نصب‌کننده باینری‌های نسخهٔ ثابت را می‌سازد و رابط، NAT و systemd را راه‌اندازی می‌کند. کلید خصوصی سرور در اختیار وب نیست. کانفیگ PLACEHOLDER تولید نمی‌شود و دانلود کانفیگ مجوز جدید نمی‌دهد.
- **SSL:** صدور به سرویس جداگانهٔ Certbot/Nginx منتقل شد. گواهی ناموفق با گواهی خودامضا جایگزین نمی‌شود. تایمر تمدید، deploy hook، سطح دسترسی کلیدها و تازه‌سازی گواهی هسته اضافه شد. بارگذاری دستی، تمدید خودکارِ کاذب ثبت نمی‌کند.
- **نشست‌ها:** دادهٔ IPهای آنلاین از API هستهٔ محلی می‌آید. مدیر فقط کاربران محدودهٔ خودش را می‌بیند. قطع اتصال و محدودیت IP، قانون واقعی همان کاربر/IP را اعمال می‌کند؛ حذف رکورد حافظه به‌تنهایی قطع موفق اعلام نمی‌شود.
- **تست مسیر:** شبیه‌سازی تقریبی حذف شد. نتیجه از `RoutingService.TestRoute` هسته و geodata بارگذاری‌شده دریافت می‌شود.
- **2FA:** کلیدها رمزگذاری و کدهای بازیابی با HMAC وابسته به کلید نصب نگهداری می‌شوند. اطلاعات قدیمی منتقل می‌شود. مصرف کد بازیابی اتمیک است؛ استفادهٔ دوباره از TOTP رد می‌شود. تغییر وضعیت 2FA نشست‌های قبلی را باطل می‌کند و setup به حساب و زمان اعتبار مشخص وابسته است.
- **ارتقای دیتابیس:** ستون‌های جدید حساب‌ها و اینباندها بدون حذف داده و به‌شکل تکرارپذیر اضافه می‌شوند.
- **WARP:** شکست ثبت حساب خطا برمی‌گرداند؛ ساخت کلید محلی ثبت موفق محسوب نمی‌شود.
- **بکاپ:** peer، کلید و تنظیمات AWG و تنظیمات DNS در بازیابی داده پوشش داده می‌شوند. بکاپ‌های قدیمی بدون جدول AWG پذیرفته می‌شوند.
- **گزارش عملیات:** مسیر تغییر نسخهٔ هسته که فقط یک تنظیم ذخیره می‌کرد، دیگر موفقیت کاذب گزارش نمی‌دهد. ری‌استارت هسته نیز فقط با همین عنوان گزارش می‌شود.

## آزمایش‌ها

- ساخت فرانت‌اند و تست‌های بک‌اند، شامل مرز مجوز مدیران و مصرف هم‌زمان کد بازیابی.
- اجرای واقعی Xray، بررسی قواعد مسیر، مشاهدهٔ IPهای اتصال VLESS و قطع اتصال موجود پس از اعمال مسدودسازی.
- ساخت AmneziaWG از سورس ثابت در لینوکس، handshake و عبور payload بین دو network namespace، و حذف peer توسط سرویس همگام‌سازی.
- اعتبارسنجی ورودی و فرمان‌های سرویس root و رد خطاهای صدور SSL و ثبت WARP.

## محدودیت‌های عملی

1. شمارش IP، شمارش دستگاه فیزیکی نیست؛ دستگاه‌های پشت NAT ممکن است یک IP داشته باشند. این قابلیت مخصوص Xray محلی است؛ نود راه دور و WireGuard/AWG در این شمارنده نیستند.
2. اعمال محدودیت یا قطع اتصال موجود، هستهٔ محلی را ری‌استارت می‌کند و دیگر کاربران نیز باید دوباره متصل شوند. کنترل حدود هر پنج ثانیه است و IP اضافه ده دقیقه مسدود می‌ماند. قطع دستی علاوه بر مجوز کاربر، مدیریت هسته می‌خواهد.
3. صدور و تمدید عمومی Let’s Encrypt، ارتباط AWG از اینترنت و سازگاری برنامه‌های کلاینت باید روی سرور و شبکهٔ مقصد آزمایش شوند. تست ایزوله جای آن را نمی‌گیرد.
4. صدور گواهی در پنل، نگاشت virtual host یا دامنهٔ پنل را عوض نمی‌کند. گواهی اولیهٔ پنل و گواهی کاتالوگ، lineage مستقل دارند.
5. این اصلاحات جای ممیزی جامع امنیتی یا تضمین کارکرد روی تمام شبکه‌ها را نمی‌گیرد.
