# مسیر بخش‌های پنل و مجوز مدیران

منو سه گروه اصلی دارد. روی عنوان هر گروه بزنید تا باز شود؛ گروه مربوط به صفحهٔ فعلی خودکار باز می‌ماند. در صفحه‌های کوتاه، خود منو قابل اسکرول است.

## کاربران و اشتراک‌ها

- **کاربران:** ساخت کاربر، حجم و انقضا، دسترسی کانفیگ‌ها، ساب و QR.
- **اشتراک‌های گروهی:** سهمیه و دسترسی مشترک چند کاربر.
- **پلن‌ها:** الگوی حجم و مدت برای ساخت یا تمدید کاربران.

## شبکه

- **ورودی‌ها (Inbounds):** پروتکل و پورتی که کاربر به آن وصل می‌شود.
- **خروجی‌ها (Outbounds):** سرور از چه مسیری ترافیک را به اینترنت می‌فرستد.
- **قوانین مسیریابی:** کدام دامنه، IP، پروتکل یا اینباند از کدام خروجی استفاده کند.
- **تونل‌های DNS:** پروفایل و وضعیت DNSTT/NoizDNS.
- **نودها:** سرورهای متصل به پنل.
- **هستهٔ Xray:** اعمال کانفیگ، راه‌اندازی، وضعیت و پیش‌نمایش کانفیگ.

### ساخت خروجی

در **خروجی‌ها** سرور محلی یا نود را انتخاب کنید. چهار خروجی آماده وجود دارد:

| خروجی | کاربرد |
| --- | --- |
| Direct | اتصال مستقیم از سرور |
| IPv4 | اتصال با راهبرد اجباری IPv4 برای DNS |
| Block | مسدودکردن ترافیک انتخاب‌شده |
| WARP | خروج از حساب WireGuard/WARP تنظیم‌شده |

با **افزودن خروجی** می‌توانید پراکسی SOCKS5 یا HTTP تعریف کنید. شناسه باید با `proxy-` شروع شود؛ آدرس و پورت را جدا وارد کنید. اگر پراکسی نیاز به احراز هویت دارد، نام کاربری و رمز را وارد کنید. رمز در دیتابیس رمزگذاری می‌شود و هنگام ویرایش، خالی‌بودن کادر رمز یعنی حفظ مقدار قبلی. در این نسخه، فرم پراکسی برای SOCKS5/HTTP استاندارد است؛ زنجیره، تجمیع خروجی‌ها و تنظیم TLS برای پراکسی بالادستی در این فرم وجود ندارد.

پس از ذخیره، خروجی را به‌عنوان پیش‌فرض یا در **قوانین مسیریابی** انتخاب کنید. حذف خروجی‌ای که هنوز پیش‌فرض یا مقصد یک قانون است پذیرفته نمی‌شود؛ ابتدا آن ارجاع را تغییر دهید. اعمال روی هستهٔ محلی در همگام‌سازی بعدی انجام می‌شود و روی نود راه‌دور به دریافت تنظیمات توسط عامل نود وابسته است. ذخیره‌شدن مشخصات پراکسی به معنی تأیید اتصال آن نیست؛ آدرس و حساب بالادستی باید واقعاً در دسترس باشند.

برای WARP، لینک **تنظیم حساب WARP** را در صفحهٔ خروجی‌ها باز کنید. کلید خصوصی، کلید عمومی طرف مقابل، Endpoint و آدرس‌های تخصیص‌یافتهٔ حساب خودتان را وارد کنید. ساخت حساب WARP به‌صورت خودکار انجام نمی‌شود.

## مدیریت پنل

- **مدیران و مجوزها:** حساب مدیران و تعیین دسترسی هر نفر.
- **امنیت و Fail2ban:** وضعیت محافظت SSH، IPهای مسدود و سیاست تلاش ورود.
- **بکاپ و بازیابی:** دریافت فایل بکاپ و بازیابی با پیش‌نمایش؛ مخصوص مالک پنل.
- **ربات تلگرام:** تنظیم ربات، دسترسی مدیران ربات و ارسال بکاپ با تلگرام.
- **تنظیمات عمومی:** برند، پیام‌ها، دامنهٔ ساب و مقادیر پیش‌فرض.
- **گزارش فعالیت:** عملیات ثبت‌شدهٔ مدیران.
- **حساب من:** تغییر رمز همان حسابی که با آن وارد شده‌اید.

## مجوز Fail2ban و خروجی‌ها

مالک در **مدیران و مجوزها ← ویرایش مدیر ← مجوزهای سفارشی** دسترسی‌ها را انتخاب می‌کند:

| مجوز | کاربرد |
| --- | --- |
| مشاهده وضعیت Fail2ban | مشاهدهٔ وضعیت SSH و IPهای مسدود |
| مدیریت Fail2ban و IPهای مسدود | مسدودکردن، رفع مسدودیت و تغییر سیاست تلاش ورود |
| مشاهده خروجی‌ها و مسیریابی | مشاهدهٔ خروجی‌ها، حساب WARP و قوانین |
| مدیریت خروجی‌ها و مسیریابی | افزودن و ویرایش خروجی، حساب WARP و قوانین |

مجوز مدیریت، مشاهدهٔ همان بخش را نیز فعال می‌کند. نقش عادی «مدیر» به‌صورت پیش‌فرض امکان مشاهدهٔ این دو بخش را دارد؛ تغییر تنظیمات نیاز به مجوز مدیریت مستقل دارد. این مجوزها در سطح سرور هستند. مدیر نمی‌تواند مجوزی بالاتر از دسترسی خودش به دیگری بدهد. کاربران بدون مجوز، لینک آن بخش را در منو نمی‌بینند و API نیز درخواستشان را رد می‌کند.

## فعال‌کردن سرویس Fail2ban روی Linux

در نصب جدید با اسکریپت، Fail2ban و سرویس رابط نصب می‌شوند. در نصب موجود:

```bash
sudo bash /opt/spectergate/deploy/fail2ban_install.sh
sudo systemctl status spectergate-security fail2ban
sudo fail2ban-client status sshd
```

صفحهٔ امنیت، jail مربوط به **SSH** را مدیریت می‌کند. تعداد تلاش ناموفق، بازهٔ بررسی و مدت مسدودیت قابل تغییر است. IP نشست فعلی، آدرس‌های خصوصی و loopback از داخل پنل مسدود نمی‌شوند. تغییرات در گزارش فعالیت ثبت می‌شوند. محافظت ورود وبِ پنل با محدودسازی برنامه و Nginx جداگانه انجام می‌شود.

برنامهٔ وب با کاربر عادی اجرا می‌شود. سرویس رابط محلی فقط عملیات مشخص Fail2ban را از یک سوکت Unix با دسترسی محدود می‌پذیرد؛ پنل به اجرای فرمان دلخواه با root دسترسی نمی‌گیرد. روی Windows یا Docker بدون رابط میزبان، صفحه وضعیت «در دسترس نیست» نشان می‌دهد.
